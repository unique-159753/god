# 三静态参考区 Raman 扫描：独立数值方法审查

本记录审查既有 `model.py`，不修改其 Hamiltonian 或推进代码。主任务以用户最后明确的规格为准：无量纲频率 ω/t₀∈[0,10]、50点；相位50个不重复周期点；V=0.5、2、4，W=0、θ=0、L=89、α=55/89、PBC。物理频率标定是附加信息，不能改变主扫描的无量纲坐标。

## 1. 坐标和零频率

若另需 Hz 映射，物理时间 t 与程序无量纲时间 τ 满足 τ=t₀t/ℏ=2π(t₀/h)t。故 Ω=ℏ2πf/t₀=f/(t₀/h)，程序周期为 2π/Ω，物理周期为1/f；不能在 Ω=f/(t₀/h) 之后再额外乘2π。未给定 t₀/h 时不能为 Hz 轴赋予固定无量纲范围。

主任务 ω=0 不是“关闭驱动”，而是字面上的时间无关 Hamiltonian：

```
Hfrozen(φ)=1.8 T + [0.5+0.8 cosφ] S + HZ.
```

这与无驱动基准 H₀=T+0.5S+HZ 不同，也不是把 f→0⁺ 的完整单周期演化简单取极限。ω=0 无周期、无 Floquet 准能量、无 Floquet 外侧20%定义；主网格该处 `quasienergies`、`outer_Dn` 等应为 NaN，外侧索引为−1，时间步为0。静态能量和全谱参与指标可以保存为有限值，但不能把静态 |E| 外侧均值冒称 Floquet 外侧均值。

## 2. 当前统一的 IPR 和 Dn

主 IPR 为178个自旋分辨分量的 Σ|ψj,s|⁴，主 Dn=−ln(IPR)/ln89。其严格概率范围是 1/178≤IPR≤1、0≤Dn≤ln178/ln89；所以 Dn 略超过1不是归一化错误。不得把以前使用ln178的 `D_component` 直接混入主图。

建议仍保存站点 IPRsite=Σj(|ψj↑|²+|ψj↓|²)²和Dsite/ln89作为辅助诊断，有 IPRspin≤IPRsite≤2IPRspin。主差值是逐态Dn先求均值，再减去同一V的无驱动静态均值；不是对平均IPR取对数。

## 3. 时间反演相位与空间对称性

所有瞬时 Hamiltonian 在原基底中为实对称。时间有序乘积给出

```
U(2π−φ)=U(φ)ᵀ.
```

对于幺正U，匹配后的本征态互为复共轭，准能量与两个IPR不变。验证时应先在准能圆周及固定对称扇区内匹配，不能简单比较排序后临近简并的任意单态标签。应抽取未用该对称性生成的真实独立φ/2π−φ演化来检查，不能把插值或对称复制当作独立验证。

θ=0时，Q=R⊗σz，反射站点零基索引为 i→(−i−2)mod89（对应物理j→−j）。Q与T、S、HZ逐一对易。C=I⊗σx给粒子空穴关系 C U* C=U，并把Q扇区交换；可从一个Q扇区准确重构配对扇区，需固定相位/排序及保留无损重构信息。

旧native偶/奇/闭环bond splitting在有限时间步下打破Q，虽然最终随加密收敛；旧FFT推进把完整kinetic和HZ分别指数化，每个因子均保持Q。固定Q基底与FFT/chiral推进适合本轮W=0的近简并问题。若对native近似U事后投影到Q块，必须报告原U的Q对易残差、投影修改量及对完整U的本征残差，不能把对称投影不加说明地视作无误差演化。

### 实际生产使用的新反射保持 native 后端

生产最终采用独立文件 `frequency_fast_native.py`，它与上面旧model.py的偶/奇/闭环拆分不同。它把89条边拆为四个各自严格保持Q的组：偶数bond共44条；奇数bond排除中间bond43后共42条；自反射中间bond43一条；闭环bond87与88联合成三站点star两条。44+42+1+2=89，没有漏边或重复。反射把非闭环bond b映为86−b，因此这些组分别在反射下闭合。SOC方向反转时满足σzRσz=Rᵀ，其中R=−tσz+Δiσy，正好补偿有向边的转置。

star在三站点顺序(87,88,0)的自旋块为

```
Hstar = [[0,R,0],[Rᵀ,0,R],[0,Rᵀ,0]],
r² = 2(t²+Δ²),  Hstar³ = r² Hstar.
```

因此其精确门为 I−i sin(rh)Hstar/r + [cos(rh)−1]Hstar²/r²；源码使用−2sin²(rh/2)/r²稳定计算后一个系数，r=0时取连续极限。独立逐项审查确认源码的一次/二次作用、SOC正负号和复数实虚部更新与此公式一致。

每个对称二阶宏阶段以各kinetic组半步、HZ整步、反序kinetic半步组成，再用下面的六阶Yoshida7子阶段组合。它仍然积分同一个真实时间依赖Hamiltonian，没有加入有效耦合或修改物理参数。新的组拆分保持Q，不能把上面旧native的粗步破Q残差套到它身上。`frequency_fast_native_validation.*`保留完整边重构、组Q对易、dense star expm、ODE及真实相位对称检查；旧FFT已算点单独保留于 `frequency_phase_three_V_fft_crosscheck/`，不混入新主网格。validator另对已有同点做实际跨后端比较。

## 4. 明确无量纲的数值压力测试

`method_benchmark.json`只测试无量纲Ω=.1、1、10，V=4、W=0、φ=π/3的数值方法；Ω=.1不属于本轮50点的正频率网格（其最小正频率为10/49≈.20408）。这些不是用某个假设的Hz标定计算出的物理相图，也不能冒充主扫描结果。

该诊断在用户新规范确认前执行，保存的 `mean_D`、`outer_D`、`max_D_change` 明确使用旧模型 `D_component` 即ln178归一化。只有原始IPR、算符差和重叠可直接比较；转换到新Dn需乘ln178/ln89。

旧native后端的真实压力测试说明：

| Ω | 时间步变化 | 相邻传播子相对Frobenius差 | 最大匹配逐态旧D变化 | 结论 |
|---:|---:|---:|---:|---|
| .1 | 32→64 | 1.41094 | .11193 | 严重未收敛，尽管幺正残差约10⁻¹⁴ |
| .1 | 512→1024 | .27596 | .16780 | 1024步仍不足 |
| .1 | 8192→16384 | 5.15×10⁻⁶ | 7.74×10⁻⁵ | 需要继续加密以达到严格算符容差 |
| 1 | 32→64 | .12893 | .23490 | 外侧均值几乎不变也不能判定单态收敛 |

## 5. 自适应检查建议

每点从M32开始，与64比较；未满足全部条件时继续128、256、…，保存实际采用的M和完整收敛历史。建议联合要求：

- 相邻完整（或严格对称等价）传播子相对Frobenius差≤10⁻⁶；
- 固定Q标签内Hungarian匹配的最大逐态Dn差≤10⁻⁴；
- 全谱平均Dn与外侧平均Dn变化均≤10⁻⁵；
- 匹配后的硬外侧成员未交换；
- 幺正、本征、正交残差分别保持可接受水平。

近简并时应另看子空间主角和基底敏感性；单态重叠低不应被解释成物理相变。低频只用绝对准能差可能造成假收敛，因为准能本身随Ω缩小；传播子相位差或2πδε/Ω更合适。几乎抵消的谱均值也可能掩盖较大单态误差，故不能单独使用均值。

本轮生产最终明确选择 `integration_order=6`，从每周期M32宏步起自适应；`frequency_solver.py`为兼容旧调用仍默认4阶，扫描入口显式传6阶，验证脚本从metadata读取同一阶数。六阶对称组合采用7个second-order子阶段，其系数为 (a,b,c,1−2(a+b+c),c,b,a)，a=.7845136104775573、b=.2355732133593581、c=−1.177679984178871。每子阶段仍在真实中点时间评估原Hamiltonian，负权重阶段也真实推进扩展时间坐标。

`order6_benchmark.json`保留独立ODE验证与四阶对照，决定依据是低频相同精度下六阶所需宏步明显减少，而非把六阶当成高频有效展开。M表示每周期宏步数；4阶每宏步含3子阶段、6阶含7子阶段，另含空间指数因子。它们均为真实时间有序数值积分，不是高频有效Hamiltonian。最终报告需明确实际方法，不把“exact Floquet”误读为没有离散误差。

## 6. 物理结论范围

V=.5、2、4是用户指定的延展/临界/局域静态参考区标签。L=89、α=55/89、PBC只是有限有理逼近系统；单尺寸IPR/D变化、准能折叠或窄参数结构不能确立热力学局域化相变。外侧20%随参数重新选择，既含同态变化也可能含成员交换。主图应只比较相同定义、相同色标及相同驱动参数的有限尺寸响应。

本审查未改变model.py，也没有用高频模型代替exact数据。`validate_frequency_scan.py`将独立检查全网格定义与零频NaN语义，并以少量代表点的M32/64/128和独立ODE演化补充验证。
